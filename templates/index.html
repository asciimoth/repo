[01] Add this repository

Choose the commands for your system. Replace PACKAGE_NAME with a name from the package list below.

Debian and Ubuntu (APT)

Install the public key and APT source file, then update APT and install a package.

curl -fsSLo KEY.gpg "{{.BaseURL}}/KEY.gpg"
sudo install -m 0644 KEY.gpg /usr/share/keyrings/{{.Repository.RPM.ID}}-archive-keyring.gpg
curl -fsSLo deb.list "{{.BaseURL}}/deb.list"
sudo install -m 0644 deb.list /etc/apt/sources.list.d/{{.Repository.RPM.ID}}.list
sudo apt update
sudo apt install PACKAGE_NAME

Fedora and other DNF systems (RPM)

Install the DNF repository file, then refresh metadata and install a package. DNF uses the repository's public key to verify its metadata.

curl -fsSLo rpm.repo "{{.BaseURL}}/rpm.repo"
sudo install -m 0644 rpm.repo /etc/yum.repos.d/{{.Repository.RPM.ID}}.repo
sudo dnf makecache
sudo dnf install PACKAGE_NAME

You can also download the setup files.
